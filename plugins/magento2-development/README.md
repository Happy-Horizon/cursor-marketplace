# Magento 2 Development

Cursor plugin providing rules and best practices for Magento 2 / Adobe Commerce development.

## Components

### Rules

- **magento2-conventions** - Coding standards and conventions for Magento 2 projects

## Usage

This plugin automatically applies rules when working with Magento 2 project files:
- PHP files in `app/code/`
- XML configuration files
- PHTML templates

## Customization

Edit `rules/magento2-conventions.mdc` to add your team's specific Magento 2 guidelines.

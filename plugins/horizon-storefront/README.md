# Horizon Storefront

Cursor plugin with rules for Horizon storefront work. This scaffold ships a single placeholder rule you can replace with real conventions.

## Components

### Rules

- **storefront-placeholder** — Replace with project-specific storefront, theme, and integration guidelines.

## Usage

Install via this marketplace or symlink the plugin into your Cursor plugins path. Edit `rules/storefront-placeholder.mdc` when you are ready to add real guidance.

## Customization

Add more `.mdc` files under `rules/` and tune `alwaysApply` and `globs` per rule so the right context loads for storefront, theme, or API code.
